# Bazaar Worldmaker "ตลาดขายโลก"

เครื่องมือสร้างแผนที่โลกแฟนตาซีบนช่องหกเหลี่ยม เปิดใช้ในเบราว์เซอร์ได้ทันทีโดยไม่ต้องติดตั้งอะไร

เข้าใช้ที่ https://unilight-games.github.io/bazaar-worldmaker/

## ทำอะไรได้

1. วาดแผ่นดิน ภูเขา แม่น้ำ เมือง เส้นทาง และเขตแดนของรัฐ
2. คำนวณภูมิอากาศแบบมีฤดู แล้วให้ชีวนิเวศเปลี่ยนตามความสูงกับความชื้น
3. จำลองเศรษฐกิจจากสินค้า ประชากร และเส้นทางค้า
4. เรียนวิธีสร้างแผนที่กับเนเมสไซอาร์ในบทเรียนแบบ visual novel
5. เปิดห้องชวนเพื่อนมาแก้แผนที่ผืนเดียวกันพร้อมกัน

## แผนที่เก็บไว้ที่ไหน

แผนที่ทุกผืนเก็บอยู่ในเบราว์เซอร์ของเครื่องที่สร้าง อยากย้ายเครื่องหรือกันข้อมูลหายให้กดสำรองเป็นไฟล์จากเมนู

หน้าเว็บบน GitHub ส่งสำเนาแผนที่ไปเก็บที่ผู้พัฒนาด้วย (ตั้งแต่ v0.18.0):

1. หน้าเว็บบอกก่อนครั้งแรก และไม่ส่งอะไรจนกว่าผู้ใช้จะกดรับทราบ
2. สำเนาถูกส่งเมื่อผู้ใช้ออกจากแผนที่กลับมาหน้าเมนู ไม่ส่งระหว่างที่กำลังแก้
3. ปิดการสำรองและลบสำเนาที่เคยส่งไปได้ที่ด้านล่างของคลังแผนที่
4. แต่ละบัญชีฝากสำเนาได้รวมไม่เกิน 100 MB (ตั้งแต่ v0.18.3) สำเนาที่จะทำให้เกิน หน้าเว็บไม่ส่ง และแจ้งให้เก็บแผนที่เป็นไฟล์ JSON แล้วลบสำเนาอื่นออกก่อน ผู้ใช้ดู เก็บเป็นไฟล์ และลบสำเนาของตัวเองได้ที่ปุ่มจัดการที่ฝาก กฎของฐานข้อมูลรวมขนาดของรายการไม่ได้ เพดานนี้จึงนับในหน้าเว็บ ส่วนหลังบ้านห้ามบัญชีใดฝากได้ และกฎบังคับข้อนั้นจริง
4. ผู้พัฒนาเข้าห้องของใครไม่ได้ ห้องเปิดเฉพาะคนที่เจ้าของแผนที่ให้รหัส

ไฟล์ออฟไลน์ไม่ส่งอะไรออกจากเครื่อง

## คนออนไลน์ แชทกลาง และหลังบ้าน

1. หน้าเมนูบอกว่าตอนนี้มีกี่คนออนไลน์ นับทั้งคนที่เข้าสู่ระบบและคนที่ไม่ได้เข้าสู่ระบบ
2. แชทกลางอ่านได้ทุกคน พิมพ์ได้เฉพาะบัญชี Google ข้อความละไม่เกิน 300 ตัวอักษร ห่างกันอย่างน้อยสามวินาที ข้อความทั้งหมดถูกล้างทุกเที่ยงคืนตามเวลาประเทศไทย
3. หลังบ้านเห็นได้เฉพาะบัญชีของผู้พัฒนา มีรายชื่อคนออนไลน์และตำแหน่งบนหน้า (เมนู แผนที่ ห้อง หรือบทเรียน ไม่บอกว่าแผนที่ผืนไหน) หน้าสถิติ (ตัวเลขสรุป กราฟการเข้าต่อวันและตามช่วงเวลา ที่ฝากของแต่ละบัญชี และพื้นที่ฐานข้อมูล) บันทึกการเข้าออกรายวัน สำเนาแผนที่ การห้ามฝากแผนที่ และการห้ามพิมพ์ในแชท

## ห้องออนไลน์

1. เจ้าของแผนที่กับเพื่อนเข้าสู่ระบบด้วยบัญชี Google ก่อน
2. เจ้าของเปิดห้องจากแผนที่ของตัวเอง แล้วส่งรหัสห้องให้เพื่อน
3. ข้อมูลแผนที่อยู่ในเครื่องเจ้าของตลอด เจ้าของออกจากห้องเมื่อไร ทุกคนหลุดออกทันที
4. เจ้าของเห็นว่าใครเข้ามา ดูสถานะของแต่ละคน เตะออก และแบนจากแผนที่ผืนนั้นได้

ข้อความระหว่างเครื่องวิ่งผ่าน Firebase Realtime Database แล้วถูกลบทิ้งภายในครึ่งนาที เซิร์ฟเวอร์ทำหน้าที่ส่งต่ออย่างเดียว

## โครงของ repo

| ที่อยู่ | คืออะไร |
|---|---|
| `index.html`, `engine/`, `assets/` | หน้าเว็บที่ GitHub Pages เปิดให้เข้า |
| `firebase-config.js` | ค่าของโปรเจกต์ Firebase ที่หน้าเว็บใช้ |
| `database.rules.json` | กฎของ Realtime Database ชุดที่ใช้อยู่ |
| `src/` | ซอร์สของเอนจิน |
| `test/` | ชุดทดสอบ (Playwright) |
| `build.py` | ตัวประกอบไฟล์ |

## สร้างใหม่จากซอร์ส

```
python3 build.py
```

ได้สามชุด `dist/` สำหรับ Claude artifact, `dist-offline/` เป็นไฟล์เดียวที่เปิดจากเครื่องได้เลย และ `dist-web/` สำหรับ GitHub Pages จะอัปเดตหน้าเว็บให้คัดลอกของใน `dist-web/` มาทับที่รากของ repo

## ย้ายไปใช้ Firebase ของตัวเอง

1. สร้างโปรเจกต์ Firebase เปิด Authentication แบบ Google และแบบ Anonymous แล้วเพิ่มโดเมนของหน้าเว็บในรายการ Authorized domains
2. สร้าง Realtime Database แล้ววางเนื้อหาของ `database.rules.json` ลงในแท็บ Rules
3. แก้ค่าใน `src/web/firebase-config.js` ให้เป็นของโปรเจกต์ใหม่ แล้วสร้างใหม่
4. ตั้งบัญชีผู้พัฒนาให้เปิดหลังบ้านได้ มีสองทาง เลือกทางใดก็ได้: (ก) ในไฟล์กฎ แทนคำว่า `ADMIN_EMAIL` ทุกจุดด้วยอีเมล Google ของผู้พัฒนาก่อนวาง แล้วเข้าสู่ระบบด้วยบัญชีนั้น ปุ่มหลังบ้านก็ขึ้นเอง หรือ (ข) เข้าสู่ระบบด้วย Google บนหน้าเว็บ คัดลอกรหัสบัญชีในระบบที่ขึ้นใต้ชื่อในการ์ดแก้แผนที่ร่วมกัน แล้วในแท็บ Data ของ Realtime Database เพิ่ม `bw/admin/<รหัสบัญชี>` ค่า `true` ถ้าใช้ทาง (ข) อย่างเดียว คำว่า `ADMIN_EMAIL` ที่เหลือในกฎไม่ตรงกับอีเมลใด จึงไม่เปิดช่องให้ใคร
